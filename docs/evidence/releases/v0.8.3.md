## 产品修复边界（源码 / CHANGELOG，不是 live PASS）

以下来自仓库 `CHANGELOG.md` 的 `[0.8.3]` 段与 release source 源码意图，只说明
该版本**声称修复/收紧的范围**，不证明最终 DMG 上每一项均已 installed/live 验证：

- Claude Science 0.1.25 兼容：updater runtime、new-session control、authority
  tree、health、managed reattach、stop/recovery identity；
- Science authority 从整树备份改为选择性 snapshot；`conda` / `runtime` /
  `seed-assets` / `r-libs` / `sbx-bind-src` 保持 opaque；
- **设为当前**只保存本地选择，**一键开始**才是校验/应用/启动/打开 Science 的
  受管事务；
- managed Science/Gateway 对 stale receipt、PID reuse、unproven restart、late
  SSH failure 与不完整 authority recovery 的收紧；
- 本地拒绝畸形 OpenAI Responses tool arguments；
- provider 卡片与 Science 显示名简化，同时保留严格 selector / role 映射。
