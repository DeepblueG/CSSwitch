## 字段可复核性

| 字段 | 本页依据 | 仓库外独立复核 |
|---|---|---|
| peeled tag / release source | 历史执行 + 本地 Git | `git rev-parse 'v0.8.4^{}'` |
| annotated tag object | 历史执行 + 本地 Git | `git rev-parse v0.8.4` |
| GitHub 公开 / 非 draft / 时间 / 附件名 size digest | 历史执行；2026-07-30 远端元数据复核 | `gh release view v0.8.4` |
| DMG SHA-256 | 历史最终本地 DMG 与公开重下载一致；64 hex | 重新下载后 `shasum -a 256`；应与 GitHub digest 一致 |
| source gate run id / completion seal / Rust 汇总 | 历史执行叙述 | 仓库**未**检入该 run 的机器可读 seal；不能仅从 Git 复算 |
| Gateway SHA-256 | 历史最终 app 记录；64 hex | 需对应 app/DMG 内二进制；仓库无该二进制 |
| Desktop SHA-256 | 历史字符串长度非法（63 hex），**已废止** | 须对 exact app 重算；不得补全或猜测 |
| installed `/Applications` 身份 | 历史安装观测（版本 0.8.4、单 app）；**不含**可用 Desktop hash | 需当时机器状态；不能由 tag 外推 |
| ad-hoc `codesign --verify` | 历史执行叙述 | 需对具体 app 重跑；不是 Developer ID |

因此：tag 与公开 DMG digest 可从 Git/GitHub 独立复核；run id、Gateway hash 与
installed 观测是**绑定历史候选的执行记录**；Desktop hash 因字段损坏已从可声明
身份中移除，不是仓库内可复算的机器事实。
